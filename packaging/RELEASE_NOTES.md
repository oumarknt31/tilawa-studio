Tilawa Studio: subtitled Quran recitation videos, made automatically.
Tilawa Studio : des vidéos de récitation du Coran sous-titrées, automatiquement.

## Installer en une ligne / Install with one line

**Mac (Apple Silicon, M1 or newer)**: open **Terminal** (⌘-Space, type "Terminal"), paste this line and press Enter /
ouvre **Terminal** (⌘-Espace, tape « Terminal »), colle cette ligne et appuie sur Entrée :

```bash
curl -LsSf https://raw.githubusercontent.com/oumarknt31/tilawa-studio/main/install.sh | bash
```

**Windows 10/11**: open **PowerShell** (Start menu, type "PowerShell"), paste this line and press Enter /
ouvre **PowerShell** (menu Démarrer, tape « PowerShell »), colle cette ligne et appuie sur Entrée :

```powershell
irm https://raw.githubusercontent.com/oumarknt31/tilawa-studio/main/install.ps1 | iex
```

The first installation also downloads the recognition model (~1.2 GB) once.
Updates are done from inside the app (✨ *Update* button). Projects and videos are kept.

La première installation télécharge aussi le modèle de reconnaissance (~1,2 Go), une seule fois.
Les mises à jour se font depuis l'app (bouton ✨ *Mettre à jour*). Les projets et vidéos sont conservés.
